# План «Ящика»

«Ящик» — почтовый клиент для Windows и Android на общем модуле [kit](https://github.com/primus-fixer/kit):
все ящики в одном месте, письма в зашифрованной базе на устройстве, никаких сторонних серверов. Сначала для
себя, позже — для семьи и коллег. Первое приложение на заготовке kit (`scripts/new-app.py`).

## Решения

| Вопрос | Решение |
|---|---|
| Ящики | Яндекс, Gmail, Mail.ru и любой ящик с IMAP/SMTP; рабочий ящик — на Яндекс 360 для бизнеса (IMAP и пароли приложений включены). Exchange не нужен |
| Вход в ящики | Пароли приложений; вход через Google (OAuth) — если Google их уберёт, через OAuth Яндекса — запасной путь |
| Хранение писем | Настройка на каждом устройстве: всё, последние N месяцев или только заголовки; там же — сколько места занято. Самый большой ящик — 1–10 ГБ |
| Новые письма на телефоне | Настройка: сразу (фоновая служба `specialUse`, уведомление как можно незаметнее), примерно раз в 15 минут (WorkManager), только в открытом приложении. На компьютере — работа в трее |
| Обмен между устройствами (kit) | Ящики и пароли, отложенные письма и «отправить позже» |
| Первая версия | Чтение, ответ, пересылка, вложения; новое письмо простым текстом; единые входящие и цепочки; поиск по всей почте с русскими словоформами; «отложить» и «отправить позже» |
| Подсказка адресов | Только из переписки, адресной книги нет |
| После первой версии | Рассылки отдельно (List-Id, List-Unsubscribe, RFC 8058); шифрование PGP (rPGP, Autocrypt) |
| Поздние доработки | Оформление нового письма; шаблоны и подписи; журнал обращений Claude |
| Claude | Коннектор: искать, читать, готовить черновики. Отправлять, пересылать и удалять не может |
| Архив | Архив всего ящика — по кнопке в настройках (формат копии kit, на диск или в облако) |
| Раскладка | Как у «Полки»: на телефоне список и нижняя панель, на компьютере меню слева; письмо открывается вместо списка |
| Не в плане | Связь с «Карманом», адресная книга, приглашения на встречи |

## Устройство

- `crates/yashik-core` — ядро: почтовая часть (IMAP, SMTP, разбор писем, цепочки, поиск, безопасный HTML) и
  чем «Ящик» отличается от других приложений на kit.
- `app/src-tauri` — приложение Tauri: база, вход, обмен, фон и уведомления, команды экранов.
- `app/src` — экраны.
- Письма — в своих таблицах той же базы SQLCipher (`Store::conn`), вложения — отдельными зашифрованными файлами.
  В журнал kit (обмен между устройствами) попадают только ящики с паролями, отложенные и «отправить позже».
- «Отложить»: письмо — в папку «Отложенные» на сервере, время — в журнале kit; вернёт любое работающее устройство.
  «Отправить позже»: письмо ждёт в «Черновиках», время — в журнале kit; первым отправляет устройство, где его
  запланировали, остальные — через несколько минут и только если письма с тем же Message-ID нет в «Отправленных».
- Кандидаты в библиотеки: `async-imap`, `lettre`, `mail-parser`, `mail-builder`, `ammonia`, `rust-stemmers`, `pgp`.

## Этапы

1. **Заготовка kit и каркас «Ящика»** — kit 0.12.0: вход, настройки (вид, вход, обмен по Wi‑Fi, облако), сборки;
   экраны «Входящие», «Папки», «Поиск» пока пустые.
2. **Один ящик: читать и писать** — Яндекс по паролю приложения; папки, список, письмо с безопасным HTML,
   вложения; новое письмо простым текстом, ответ, пересылка, черновики.
3. **Все ящики** — Gmail, Mail.ru, рабочий ящик, любой IMAP с автонастройкой; единые входящие и цепочки;
   старые кодировки; хранение по настройке; работа без сети; ящики и пароли — между устройствами через kit.
4. **Поиск по всей почте** — индекс FTS5 с русскими словоформами, фильтры, поиск на сервере.
5. **Уведомления, «отложить», «отправить позже»** — трей на Windows, три режима на Android; на любом
   устройстве, без двойной отправки. После этого этапа «Ящик» заменяет старый клиент.
6. **Копии и архив** — копия настроек; архив всего ящика по кнопке, проверка и восстановление.
7. **Коннектор для Claude** — поиск, чтение, черновики; какие ящики видит Claude.
8. **Рассылки отдельно.**
9. **Шифрование PGP.**
10. **Поздние доработки** — оформление нового письма, шаблоны и подписи, журнал обращений Claude.

## Что добавится в kit

Работа в фоне на компьютере (трей), фоновая служба и уведомления на Android, зашифрованные файлы на устройстве,
строка «Место на устройстве», новые общие элементы экрана — когда понадобятся «Ящику» и пригодятся другим.

## Риски

- Android: мгновенная проверка держится на фоновой службе, у которой всегда есть уведомление; делаем его тихим,
  на Android 13 и новее его можно смахнуть. Тип службы `specialUse`: у `dataSync` с Android 15 предел 6 часов в сутки.
- Gmail может убрать пароли приложений — тогда вход через Google (OAuth).
- Первая загрузка ящика в 1–10 ГБ: заголовки сначала, тексты новыми первыми, вложения по настройке.
- Подсказки для Claude внутри писем: у коннектора нет инструментов, которые отправляют или удаляют.
